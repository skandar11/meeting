# operations/ — что агент умеет делать

Файл на действие, форма — [[operation-template]]. Агент действует по операции,
а не по памяти.

**На запись** — процедуры изменения: завести, поправить, отметить, принять, закрыть.

**На ответ** — процедуры чтения: на каждый вопрос, который пользователь задаёт
регулярно. Не забывай про них: база, умеющая только писать, перевёрнута —
человек чаще спрашивает, чем диктует.

Новая операция — строкой в `CLAUDE.md` и в [[HOME]], иначе агент её не найдёт.

Соседние места (заводятся с первым файлом, не раньше): `vault/tools/` — памятки
внешних инструментов ([[tool-template]]); `vault/processes/` — цепочки операций
к бизнес-исходу ([[process-template]]).
