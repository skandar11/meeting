# Решения по базе

Решения об устройстве базы — по одному файлу, датировано: `YYYY-MM-DD-краткое-имя.md`.

Сюда попадает то, что легко забыть — «почему так»: почему поле убрали, почему
раскладка такая, какой разворот сделали и что при этом отложили.

Решения по самой предметной области сюда не идут — они живут в карточках.
