# Операция — создать карточку товара

**Когда:** «заведи карточку на <товар>», «добавь новый товар», а также как
шаг 1 процесса [[vyvesti-tovar]].

**Шаги:**

1. Проверь дубль — поиск по названию в товарной зоне. Есть → обнови
   существующую карточку, не плоди вторую.
2. Собери карточку по форме зоны: название · фото · описание · цена · остаток.
   Фото и материалы даёт владелец; чего нет — вопрос ему, не выдумывай.
3. Цену и остаток сверь с базой; **сколько именно — говорит владелец, сам не
   считай**, если в базе цифры нет.
4. Черновик готов → отметь в карточке `статус: черновик`. Утверждение — гейт
   процесса, не этой операции: наружу отсюда ничего не уходит.

**Крайние случаи:** нет фото → карточка остаётся черновиком, строка владельцу
в открытые вопросы.

**Не здесь:** выкладка на площадку — [[vylozhit-na-marketpleys]].
