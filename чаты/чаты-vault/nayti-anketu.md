# Найти анкету

**Отвечает на:** «покажи анкету Н.», «кто из Караганды 45–60», «кто готов к
переезду».

## Как

1. Ищи в `чаты/data/` по имени, номеру или полям анкеты.
2. Одного человека отдай полями [[анкета]] + статус, оплаты, группы.
3. Отбор по нескольким полям — таблицей, с числом найденных.

## Где не соврать

- **Пустое поле — «в анкете не сказано»**, а не «нет».
- **Подбор пар — решение Айгуль.** Агент отбирает по полям; «подходят друг другу»
  не говорит.
- **Нашлось двое с одним именем** — покажи обоих, не выбирай.
