# Форма процесса

Процесс — цепочка операций к бизнес-исходу: «вывести товар на площадки»,
«принять нового ученика». Стоит **над** операциями: один процесс собирает
несколько операций, одна операция может служить нескольким процессам.
Лежат в `vault/processes/`, по файлу на процесс; папка заводится с первым
процессом, не раньше.

Файл процесса — тонкий: цепочка ссылок, гейты и короткие связки. Шагов-пересказов
в нём нет — шаги живут в операциях.

## Пример

~~~
---
тип: process
процесс: вывести-товар
исход: товар продаётся на всех площадках
---
# Процесс — вывести товар

1. [[создать-карточку-товара]]
2. ⏸ operator: владелец утвердил карточку
3. [[выложить-на-каспи]] — и так на каждую площадку
4. [[обновить-каталог]]
~~~

## Правила

- **Процесс знает свои операции; операция своих процессов не перечисляет.**
  Обратную связь показывают backlinks — руками её не вести, протухнет.
- **Исход обязателен** — фраза «чем это кончается». Процесс без исхода —
  просто список.
- **Не плоди процесс ради одной операции** — цепочка начинается с двух.
- Между операциями допустимы только гейты `⏸ operator` и короткие связки
  («и так на каждую площадку»). Захотелось написать шаги — им место в операции.
