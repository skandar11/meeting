# Как писать в базе

**Служебные поля — по-русски** (`тип:`, `статус:`, `действие:`) — выбрано
2026-09-14. **Знание — в vault, данные — рядом**, в `чаты/data/`.

Правила, чтобы база оставалась связной и по ней можно было отвечать. Копируются
в каждую построенную базу — там их можно уточнять под область.

- **Одна карточка = один объект.** Один человек — один файл, один месяц — один файл,
  одна вещь — один файл. Не сваливай разное в кучу.
- **Связи через `[[wikilinks]]`.** Граф строится только из них. Ссылка на ещё не
  созданный файл — нормально, она помечает, что его стоит завести. А вот ссылка
  на **папку** не работает никогда: на папку пиши путь как код — `люди/`.
  И внутри таблицы пипу в ссылке надо экранировать: `[[id\|Имя]]`.
- **Имя файла уникально по всей базе.** Ссылки ищут по имени, а не по пути: два
  `income.md` в разных папках — и связи поедут.
- **Одно поле — одно место.** Дублируешь — реши, где истина, и во втором месте
  поставь ссылку, а не копию. Разошлось — верь тому месту, которое названо главным.
- **Данные людей живут в карточках**, если репозиторий приватный. Это надо
  **обеспечить, а не заявить**: пока репозитория нет, писать «репозиторий приватный»
  нельзя.
- **В `secrets/` — только секреты:** токены, ключи, пароли. Имя всегда `secrets/`,
  других вариантов нет. Персональные данные — не секреты, это разные вещи: карточки
  и документы с ПД спокойно едут в приватном репозитории, в `secrets/` им не место.
- **Заголовки лёгкие** — см. [[vault-template]]: вид объекта всегда, дальше только
  поля этого вида. **Язык служебных полей выбирается один раз на базу** и дальше не
  смешивается: либо всё на языке владельца, либо всё латиницей. Оба варианта живые;
  смешанный — нет, он и даёт две редакции формы. Выбор записывается в
  `principles.md` построенной базы первой строкой.
- **Действия — операциями**, по [[operation-template]]. Агент действует по
  операции, а не по памяти.
- **Новый род вещей — зона**, по [[zone-template]]. На глаз зоны не заводятся.
- **Пиши простым языком, словами владельца.** Базой пользуется человек своего дела,
  не программист.
- **База одноуровневая.** Никаких «уровней», «проекций» и прочей внутренней
  машинерии конструктора — в построенную базу этот язык не едет.
- **Откуда цифра — говорит сама цифра, если данные снятые.** База, собранная из
  выгрузок и снимков чужих систем, обязана носить дату снимка при каждом числе и
  прямо отличать «владелец подтвердил» от «агент снял». База, которую владелец
  наполняет сам, в этом различении не нуждается — не заводи его без надобности.
