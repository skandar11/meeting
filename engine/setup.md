# Настройка engine на Маке

Скрипты читают WhatsApp для Mac **только на чтение**: ничего в него не пишут,
ничего не отправляют, в интернет ничего не выгружают. Секретов не нужно —
`secrets/` пуст.

## 1. Command Line Tools — git и python3

```bash
xcode-select --install
```

Откроется окно установки — «Установить». Ставится минут 10–20, фоном. Проверка:

```bash
git --version
python3 --version
```

## 2. WhatsApp для Mac

- **Обычный WhatsApp**, не Business.
- **Привязан к телефону Айгуль** (QR-код в приложении) и **открыт**: история и
  новые сообщения попадают на Мак, только пока приложение работает.
- Его база: `~/Library/Group Containers/group.net.whatsapp.WhatsApp.shared/ChatStorage.sqlite`.

## 3. Доступ macOS

При первом запуске macOS может спросить, разрешить ли доступ к данным другого
приложения — **разрешить**.

Не спросила, а скрипт пишет «не открылась база»: Системные настройки →
Конфиденциальность и безопасность → Полный доступ к диску → включить
приложение, из которого запускается скрипт (Claude или Терминал) →
перезапустить его.

## 4. Запуск — из корня базы

| Команда | Что делает |
|---|---|
| `python3 engine/probe.py` | цифры: чаты, группы, сообщения, даты, люди в группах, анкеты, условия; текст сообщений не печатает |
| `python3 engine/probe.py --groups` | то же + группы: название, людей, сообщений, последнее сообщение |
| `python3 engine/snapshot.py` | копия базы WhatsApp в `transit/whatsapp-ГГГГ-ММ-ДД-ЧЧММ/` |

## Чего ещё нет

`engine/sync.py` — перенос из снимка в `чаты/data/`. Пишется после первого
визита, под выбранную форму данных ([[зона-данных]]).
